Introduction

When we round off, up or down a number, the new number is no more the actual value but an estimate or an approximated value. This is usually done in big businesses to make calculations easier for professionals like bankers.

We will be making use of this symbol \(\left(\approx\right)\), which is read as "approximately".

What are Decimals?

A decimal is another form of expressing fractions.

It can also be thought of as a part of an interval and is usually expressed in the form of a whole part and fractional part being separated by a decimal point

Example is 12.389

Remember

When rounding off, up or down a number, you need to consider whether the number to the immediate right of the place value you are rounding is part of any of the following sets of numbers:

Small Digits

\[ \{0, 1, 2, 3, 4\} \]

Big digits

\[ \{5, 6, 7, 8, 9\} \]

Rounding Off, Up or Down

Main Idea

  • Off: look at the digit to the right of the place value. If it is $0$ to $4$, keep the place value; if it is $5$ to $9$, add $1$. Change the digits to its right to zero.
  • Up: if any digit to the right is not zero, add $1$ to the place value and change the digits to its right to zero. If they are all zeros, the number stays the same.
  • Down: keep the place value and change the digits to its right to zero.

Rounding Up Decimals

Main Idea

Rounding up means adding 1 to the place value (our reference point) and changing all the digits to the right to zero (0). If all digits to the right are zero, the number stays the same.

Rounding to Significant Figures

Main Idea

Significant figures (or significant digits) refer to the digits in a number that carry meaning or contribute to the number's precision. These include all non-zero digits, any zeros between significant digits, and trailing zeros in the decimal part.

Rounding to Decimal Places

Main Idea

The number of decimal places in any given number refer to the number of digits to the right of the decimal point. Example:

(a) 12.34567 has 5 decimal places.

(b) 100.004 has 3 decimal places.
