Introduction

When we round off, up or down a number, the new number is no longer the exact value. It is an estimate, or an approximate value. Bankers and other professionals use rounded numbers to make calculations easier.

We use the symbol $\approx$, which is read as "approximately".

Whole Numbers $(\mathbb{W})$

A whole number is a non-negative integer. It includes all the numbers $0, 1, 2, 3, \ldots$ and so on, without fractions or decimals.

$$\mathbf{W} = \{0, 1, 2, 3, 4, \ldots\}$$

Rounding Off, Up or Down

Main Idea

  • Off: look at the digit to the right. Small ($0$ to $4$): keep the place value. Big ($5$ to $9$): add $1$. Then change the digits to its right to zero.
  • Up: if any digit to the right is not zero, add $1$ to the place value and change the digits to its right to zero. If they are all zeros, the number stays the same.
  • Down: keep the place value and change the digits to its right to zero.

Rounding to Significant Figures

Main Idea

Significant figures (or significant digits) refer to the digits in a number that carry meaning or contribute to the number's precision. These include all non-zero digits, any zeros between significant digits, and trailing zeros in the decimal part.
